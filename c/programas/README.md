# Programas em C

Esta pasta reúne pequenos programas desenvolvidos durante meus estudos de lógica de programação e da linguagem C.

## Objetivo

Praticar conceitos fundamentais de programação por meio de exercícios e mini projetos, desenvolvendo o raciocínio lógico e a capacidade de resolver problemas.

## Conteúdos praticados

- Variáveis e tipos de dados
- Estruturas condicionais
- Estruturas de repetição
- Funções
- Vetores
- Manipulação de dados

## Organização

Cada pasta contém um programa ou mini projeto independente, desenvolvido para praticar os conceitos estudados.
